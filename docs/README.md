# Using Contour

Contour is an indoor cycling app. It connects to a smart trainer over Bluetooth, rides real
routes with the trainer simulating the gradient, records what you did and hands you a file you
can upload to Strava. There are no avatars, badges, levels or leaderboards, and there never will
be.
